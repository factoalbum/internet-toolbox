# Internet Toolbox AdSense Readiness Roadmap

Last reviewed: 2026-09-11

This roadmap tracks product quality work toward a future AdSense application. The percentages are internal planning estimates, not a Google approval score or guarantee.

## Phase 1 — Policy & Trust Foundation

**Status: DONE**

- [x] Privacy, terms, disclaimer, about, contact, and support pages
- [x] Clear browser-only/privacy messaging where applicable
- [x] Basic error, loading, and not-found states
- [x] Trust-oriented navigation and site identity

## Phase 2 — Original & Useful Content

**Status: IN PROGRESS (~70%)**

- [x] Editorial records for live tools
- [x] Tool overviews, best-use guidance, tips, limitations, and FAQs
- [x] Useful explanatory content on category pages
- [x] Automated minimum-depth checks for live-tool editorial content
- [x] Automated duplicate-copy checks across live tools
- [ ] Review every live tool for genuine standalone usefulness
- [ ] Add examples or practical guidance where a tool needs more context
- [ ] Remove, combine, or improve tools that provide too little independent value
- [ ] Complete a human-quality pass for repetitive or overly templated copy

## Phase 3 — UX, Accessibility & Navigation

**Status: MOSTLY DONE (~90%)**

- [x] Responsive tool and category layouts
- [x] Mobile navigation/sidebar
- [x] Keyboard focus states
- [x] Drawer focus management and Escape handling
- [x] Breadcrumb navigation
- [x] Search and category filtering
- [x] Clear error and empty states
- [ ] Final keyboard-only pass across every interactive tool
- [ ] Final small-screen audit across representative tools

## Phase 4 — Technical SEO / AEO

**Status: MOSTLY DONE (~90%)**

- [x] Sitemap and robots configuration
- [x] Canonical URLs
- [x] Open Graph and Twitter metadata
- [x] Tool metadata
- [x] Category metadata
- [x] BreadcrumbList structured data
- [x] ItemList structured data
- [x] FAQ structured data where appropriate
- [x] Internal search/discovery aliases
- [ ] Final metadata consistency audit across every indexable page
- [ ] Final sitemap/indexability/orphan-page audit

## Phase 5 — AdSense Readiness & Quality Audit

**Status: CURRENT (~65%)**

The goal is to make the site useful and trustworthy even without advertising. Passing automated checks is necessary but not sufficient.

- [x] Core policy/trust pages exist
- [x] Automated readiness/site audit
- [x] Live-tool editorial-content requirement
- [x] Minimum editorial-depth checks
- [x] Duplicate editorial-copy detection
- [x] Category-page informational content
- [ ] Audit individual live tools for thin or low-value experiences
- [ ] Review repetitive/template-heavy content
- [ ] Check for broken/orphaned/low-value pages
- [ ] Complete accessibility and mobile quality pass
- [ ] Complete performance review
- [ ] Complete final policy/trust/UX review from a visitor perspective
- [ ] Verify Search Console/indexing health before application

## Phase 6 — Traffic → AdSense → Optimization

**Status: NOT STARTED**

- [ ] Build sustainable organic traffic
- [ ] Monitor Search Console queries and landing pages
- [ ] Confirm site-wide quality before applying
- [ ] Apply for AdSense when the site is ready
- [ ] Add restrained, clearly separated ad placements
- [ ] Monitor Core Web Vitals, UX, search traffic, and revenue
- [ ] Optimize without allowing ads to overwhelm the tools or content

## Current priority

**Phase 5 is the active phase.** The next work should favor improving the quality and usefulness of existing live pages over adding tools merely to increase the catalogue size.

A phase is considered complete only when its checklist is satisfied and the following phase can begin without weakening site quality.
