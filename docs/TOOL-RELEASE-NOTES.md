# Recent Tool Additions

## Copy-Paste Cleaner

Cleans copy artifacts from text pasted from AI assistants and formatted apps. It detects the Claude-style vertical copy marker used in copied conversations, removes trailing spaces, reduces excessive blank lines, and leaves the wording unchanged.

## Structured File Export

Packages a local file into a well-formed XML document containing filename, extension, MIME type, size, SHA-256 checksum and Base64-encoded file bytes. The browser performs the conversion locally. The output is intentionally generic and must be mapped to any receiving system's required schema before submission.
