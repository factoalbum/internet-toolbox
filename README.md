# Internet Toolbox

Simple tools for everyday digital tasks.

## Product principles

- Fast: the tool should be usable immediately.
- Clear: users should understand what to do without instructions overload.
- Accessible: keyboard-friendly, readable and mobile-first.
- Useful: every tool must solve a real problem.
- Search-friendly: strong information architecture, metadata and helpful supporting content.
- Privacy-conscious: prefer browser-side processing when practical.

## Engineering loop

Each feature follows:

**Plan → Build → Run → Inspect → Test → Fix → Verify → Commit**

The repository is intentionally structured so tools can scale without duplicating page, SEO and UI logic.
